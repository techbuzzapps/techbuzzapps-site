Help for ColorBlitz game modes and Game Center.

Game Modes

ColorBlitz includes Classic, Endless, Daily Challenge, and Color Master. Detailed gameplay instructions will be published with the approved release documentation.

Game Center

Classic and Endless have dedicated Game Center leaderboards.

If Game Center is unavailable, confirm that the device has an internet connection and that Game Center is signed in within the device settings. Then close and reopen ColorBlitz and check again.
