# ColorBlitz Website Assets Checklist

Evidence labels: **VERIFIED IN CURRENT SOURCE**, **EXTERNAL VERIFICATION REQUIRED**, **LEGAL APPROVAL REQUIRED**.

- [ ] **App icon:** source asset exists at `ColorBlitz/Assets.xcassets/AppIcon.appiconset`; export the approved current marketing-resolution icon from the shipping asset catalog. Confirm brand approval and no simulator/debug icon. **EXTERNAL VERIFICATION REQUIRED**.
- [ ] **Screenshots:** capture current shipping UI for home/four modes, Classic combo, Endless pause/continue, Daily streak, Color Master tiers, Progress/Game Center, and Store/Premium. Verify no test data, debug overlays, unapproved prices, or fabricated player names. For Game Center, do not imply leaderboard availability until all four boards are verified in App Store Connect; use approved test captures and never expose a real player's details without permission. **EXTERNAL VERIFICATION REQUIRED**.
- [ ] **App Store link:** supply the approved live listing URL and verify it opens the correct app in intended territories. Do not synthesize from bundle ID. **EXTERNAL VERIFICATION REQUIRED**.
- [ ] **Marketing assets:** approved logo, key art, app icon export, screenshots, optional preview video, and usage rights. Keep website components aligned with TechBuzzApps shared design. **EXTERNAL VERIFICATION REQUIRED**.
- [x] **Support contact:** developer-confirmed `techbuzzapps@gmail.com`, used on the ColorBlitz Support page.
- [ ] **Approved legal information:** legal entity/brand, address/contact, jurisdiction, privacy policy URL, Terms/EULA choice, subscription language and effective dates. **LEGAL APPROVAL REQUIRED**.
- [ ] **Premium offer details:** live monthly/yearly prices, territory availability, introductory offers/trials, and renewal terms from App Store Connect. **EXTERNAL VERIFICATION REQUIRED**.
- [ ] **Game Center evidence:** App Store Connect app/leaderboard configuration and tested release associations. **EXTERNAL VERIFICATION REQUIRED**.
- [ ] **Privacy claims:** final archive manifests, SDK/provider data practices, App Store privacy answers and ATT decision. **EXTERNAL VERIFICATION REQUIRED**; publish only after **LEGAL APPROVAL REQUIRED**.
- [ ] **Website visual consistency:** use the existing TechBuzzApps colors, typography, cards, buttons, header/footer, and layout conventions shared across all apps. No Aurora gradient site, separate ColorBlitz CSS theme, or app-specific web design system.
