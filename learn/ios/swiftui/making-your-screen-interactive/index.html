4. What Exactly Is @State?

Let's break this down:

@State private var count = 0

var count

This is our variable.

count

stores an Int.

private

private var count

means this state belongs to this view and isn't intended to be accessed directly from outside it.

That's generally a good habit for local view state.

@State

This is the special SwiftUI part.

@State

tells SwiftUI:

This value can change, and changes to it may affect this view's UI.

So:

@State private var count = 0

can be thought of as:

"count is mutable state owned by this view."

9. What Does $name Mean? 🤔

This is one of those things that looks mysterious when you're new.

Compare:

Text("Hello \(name)")

with:

TextField("Name", text: $name)

Why does one use:

name

and the other:

$name

Because they need different things.

name

means:

Give me the current value.

If:

name = "Sam"

then:

Text(name)

needs to read "Sam".

$name

means roughly:

Give this control a connection to the value so it can read and change it.

A TextField needs that connection because when the user types, the text field needs to update name.

Changes can flow between them.

SwiftUI calls this connection a Binding.

For now, just remember:

We'll understand bindings much more deeply in a later lesson.

🛠️ Let's Build an Interactive Screen

Now let's combine everything.

struct DailyProgressView: View {

    @State private var count = 0
    @State private var name = ""
    @State private var reminderEnabled = false

    var body: some View {

        VStack(spacing: 24) {

            Text("Daily Progress")
                .font(.largeTitle)
                .fontWeight(.bold)

            VStack(spacing: 8) {

                Text("\(count)")
                    .font(.system(size: 60))
                    .fontWeight(.bold)

                Text("tasks completed")
                    .foregroundStyle(.secondary)
            }

            Button {
                count += 1
            } label: {
                Text("Complete +1")
                    .fontWeight(.semibold)
                    .frame(maxWidth: .infinity)
                    .padding()
                    .background(.blue)
                    .foregroundStyle(.white)
                    .clipShape(
                        RoundedRectangle(cornerRadius: 14)
                    )
            }

            VStack(alignment: .leading, spacing: 8) {

                Text("Your Name")
                    .font(.headline)

                TextField("Enter your name", text: $name)
                    .textFieldStyle(.roundedBorder)
            }

            Toggle(
                "Daily Reminder",
                isOn: $reminderEnabled
            )

            if count >= 5 {
                Text("🎉 Daily goal completed!")
                    .font(.headline)
            }

            Spacer()

            Button("Reset") {
                count = 0
            }
        }
        .padding()
    }
}

There's quite a bit of code here, but look at the state first:

@State private var count = 0
@State private var name = ""
@State private var reminderEnabled = false

That's our screen's data.

Then look at the UI:

And finally the user changes that data:

That's the important part of this lesson—not memorizing the syntax.

🧩 One More Important Idea: State Has an Owner

We wrote:

struct DailyProgressView: View {
    @State private var count = 0
}

That means:

DailyProgressView owns count.

This will become important later.

For now, a useful beginner rule is:

Use @State when a view owns simple UI state.

Good examples include:

@State private var count = 0

@State private var isShowingDetails = false

@State private var searchText = ""

@State private var isEnabled = true

Don't worry yet about all the other SwiftUI property wrappers you've probably seen:

We'll introduce them when there's a reason to use them.

Learning all of them at once usually makes SwiftUI unnecessarily confusing.
