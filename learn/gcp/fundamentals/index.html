GCP · Learning Track

🌱 GCP Fundamentals

A Google Cloud course for complete cloud beginners. You don't need to memorise every Google Cloud service — you'll learn the concepts first, then the services that solve each problem.

Start with Lesson 1

The Course

Each lesson solves one practical cloud problem — running a server, storing files, deploying an app, keeping it secure — and introduces Google Cloud products only when that problem needs them. The work is hands-on in the Google Cloud Console first, with Cloud Shell and the gcloud command line introduced gradually. The final lesson combines everything into one small, production-style system.

  1. Lesson 1 Getting Started with Google Cloud What cloud computing is, regions and zones, projects, the Google Cloud Console, billing, APIs and Cloud Shell — ending with a tour of your first project. →
  2. Lesson 2 Your First Server in the Cloud Virtual machines, Compute Engine, machine types, disks, external IPs, SSH and firewall basics — ending with a VM hosting a tiny webpage. Coming soon
  3. Lesson 3 Storing Files in the Cloud Cloud Storage buckets and objects, regions, permissions, uploads and downloads, and storage classes — ending with a small cloud file store. Coming soon
  4. Lesson 4 Deploying an Application Without Managing Servers Containers at a beginner level, Cloud Run, deployments, revisions, logs, environment variables and scaling — ending with a deployed web/API app. Coming soon
  5. Lesson 5 Databases in Google Cloud Relational vs NoSQL, Cloud SQL, Firestore, connecting apps to data and choosing between them — ending with an app that saves and retrieves data. Coming soon
  6. Lesson 6 Users, Permissions & Security IAM, principals, roles, service accounts, least privilege and secrets — and why not everything should get Owner. Coming soon
  7. Lesson 7 Networking Without the Headache VPCs, subnets, private and public IPs, firewall rules, DNS, load balancing and service communication — building a simple visual cloud network. Coming soon
  8. Lesson 8 Connecting Services Together Pub/Sub, events, asynchronous processing, APIs and service-to-service communication — ending with an event-driven mini system. Coming soon
  9. Lesson 9 Monitoring, Logs & Costs Cloud Logging, Monitoring, alerts, budgets, billing reports, quotas and troubleshooting — breaking something on purpose and diagnosing it. Coming soon
  10. Lesson 10 Beginner GCP Project Combine Cloud Run, a database, storage, IAM and logging into one small production-style system. Coming soon
